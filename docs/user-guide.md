# Tauricon 使用手冊

Tauricon 有兩種模式，可在視窗頂部切換：

- **App 圖示**：從一張圖產生各平台的 App 圖示（可批次處理多張）
- **圖片集**：為 App 內使用的一般圖片產生各種螢幕密度的版本

## 載入圖片

- **方式**：把圖片拖進視窗任何位置、點擊拖放區，或按 `Ctrl+O`
- **支援格式**：PNG、JPG、WebP、SVG（含 `.svgz`）
- **建議**：點陣圖 1024×1024 以上；**最推薦使用 SVG**，每個尺寸都從向量直接渲染，小圖示最清晰
- **上限**：檔案 50 MB、點陣圖 16384×16384 px

載入後會顯示檔名、類型與尺寸。以下情況會出現提醒：

| 提醒 | 說明 |
|---|---|
| 原圖不是正方形 | 會等比例縮放並置中，四周留透明 |
| 點陣圖小於 1024 px | 1024 px 的商店圖示會被放大，可能模糊 |

**最近使用**：拖放區下方會列出最近開啟的 4 個檔案，點一下即可重新載入；檔案若已移動或刪除，會自動從清單移除。

> SVG 中若含有文字，會使用系統字型渲染，不同電腦可能略有差異。建議在設計軟體中先把文字轉為外框（路徑）。

## 樣式

所有樣式都會即時反映在預覽中，預覽與實際輸出使用同一套渲染程式。

### 背景

| 選項 | 說明 |
|---|---|
| 無 | 保留原圖的透明區域 |
| 純色 | 以單一顏色填滿背景 |
| 漸層 | 兩色線性漸層，可調整角度（0° 由下往上、90° 由左往右、180° 由上往下），「⇄」可對調顏色 |

> iOS 與 watchOS 不支援透明圖示；未設定背景時，這兩個平台會自動使用白色背景。

### 內距

圖案四周保留的空白，0–40%。圖案貼邊或想讓圖示看起來更「透氣」時使用。

### 圓角

0–50%（50% 為圓形）。**只套用在系統不會自動裁切的平台**：macOS、Windows、Web、Tauri。
iOS、watchOS、Android 由系統自行套用遮罩，必須輸出方形滿版圖，因此不受圓角影響。

### macOS 標準樣板

依照 macOS 11 之後的圖示規範：主體縮小為 824/1024、加上圓角與底部陰影。開啟後 macOS 會改用樣板，不套用上方的圓角設定。

## 平台與輸出內容

在右欄勾選要輸出的平台。「全選／全部取消」可快速切換。

### 常用組合

「常用組合 ▾」可把目前勾選的平台（含 iOS 輸出模式）存成命名組合，之後一鍵套用，也可以刪除。

### 各平台輸出

| 平台 | 輸出位置 | 內容 |
|---|---|---|
| iOS / iPadOS（全部尺寸） | `ios/AppIcon.appiconset/` | 13 張 PNG（20–1024 px）＋ `Contents.json`，涵蓋 iPhone、iPad 與 App Store |
| iOS / iPadOS（單一尺寸） | `ios/AppIcon.appiconset/` | 1024 px 單張＋ `Contents.json`（Xcode 14 以上） |
| watchOS | `watchos/AppIcon.appiconset/` | 1024 px 單張＋ `Contents.json` |
| macOS | `macos/` | `AppIcon.appiconset/`（7 張 PNG＋ `Contents.json`）與 `AppIcon.icns` |
| Android | `android/` | `res/mipmap-*/`（mdpi～xxxhdpi）的一般、圓形、自適應圖層，`mipmap-anydpi-v26/` 的自適應 XML，以及 `playstore-icon.png`（512 px） |
| Windows | `windows/app.ico` | 內含 16、24、32、48、64、128、256 px |
| Web / PWA | `web/` | `favicon.ico`、16／32 px favicon、`apple-touch-icon.png`、192／512 px 圖示、`site.webmanifest` |
| Tauri | `tauri/` | 對應 Tauri 專案 `src-tauri/icons/` 的整套檔案：`icon.ico`、`icon.icns`、32–512 px PNG、Windows Store Square Logo |

### 使用方式

- **Xcode**：在專案的 `Assets.xcassets` 中刪除原本的 `AppIcon`，把輸出的 `AppIcon.appiconset` 資料夾拖進去
- **Android Studio**：把 `android/res/` 內的資料夾複製到專案的 `app/src/main/res/`，覆蓋同名檔案
- **Web**：把 `web/` 內的檔案放到網站根目錄，並在 HTML `<head>` 加入：
  ```html
  <link rel="icon" href="/favicon.ico" sizes="any">
  <link rel="apple-touch-icon" href="/apple-touch-icon.png">
  <link rel="manifest" href="/site.webmanifest">
  ```
- **Tauri**：把 `tauri/` 內的檔案覆蓋到專案的 `src-tauri/icons/`

### iOS 輸出模式

iOS 卡片上可切換「全部尺寸」與「單一尺寸（Xcode 14+）」。新專案建議使用單一尺寸，由 Xcode 自動產生其他尺寸；需要支援舊版 Xcode 時使用全部尺寸。

## Android 進階設定

Android 卡片內可設定：

| 選項 | 說明 |
|---|---|
| 圓形圖示（ic_launcher_round） | 是否輸出圓形版本 |
| 自適應圖示（Android 8.0+） | 是否輸出自適應圖示的前景、背景圖層與 XML |

點「▸ 自適應圖層」可展開更多設定：

### 圖層

| 圖層 | 預設來源 | 可改用 |
|---|---|---|
| 前景 | 主圖 | 另一張圖（建議透明背景的 logo） |
| 背景 | 樣式背景 | 另一張圖 |
| 單色來源 | 自動（前景輪廓） | 另一張圖 |

輸出會依設定自動調整：

- 背景為「無」或「純色」：輸出顏色資源 `values/ic_launcher_background.xml`
- 背景為「漸層」或指定圖片：輸出各密度的 `ic_launcher_background.png`
- XML 中的 `<background>` 會自動指向對應的資源

> 舊版圖示（`ic_launcher.png`、圓形版）與 Play 商店圖仍使用主圖與樣式背景。圖層圖片不會被記住，重新開啟 App 後需要重新選擇。

### 前景縮放

前景圖案佔自適應畫布（108dp）的比例，預設 61%。在這個比例內，圖案完整落在安全區，任何形狀的遮罩都不會裁到。

### 主題圖示（Android 13+）

輸出單色圖層 `ic_launcher_monochrome.png`，系統會依桌布配色重新上色。單色圖層只保留圖案輪廓（白色＋透明度），**前景需要是透明背景的圖**，否則會變成一整塊方形。

## 預覽

| 預覽 | 說明 |
|---|---|
| 各平台圖塊 | 以各平台實際的遮罩形狀顯示（iOS 圓角、Android 圓形與圓角、watchOS 圓形等） |
| Android 圖塊 | 開啟自適應圖示時，顯示背景＋前景的合成結果，並裁切到可見的 72dp 範圍 |

| 瀏覽器分頁 | 勾選 Web 時顯示 favicon 在分頁上的樣子 |

透明區域以棋盤格表示。

## 產生與輸出

1. 在底部列選擇 **ZIP 檔** 或 **資料夾**
2. 視需要勾選 **壓縮最佳化 PNG**：無損壓縮，檔案會更小，但產生時間較長。不會改變像素、色彩格式與位元深度，仍符合各商店規範
3. 按 **產生 N 個檔案**（或 `Ctrl+Enter`），選擇儲存位置

- **ZIP**：儲存為單一壓縮檔
- **資料夾**：會在你選的位置裡建立一個子資料夾，避免各平台資料夾散落在桌面等位置

完成後會顯示檔案數、大小與耗時，點「在檔案總管中顯示」可開啟輸出位置。

輸出名稱可在 [設定](#設定) 中自訂。

## 批次處理

在 App 圖示模式下**一次拖入或選取多張圖片**，即進入批次模式：

- 左欄會出現「批次（N 張）」清單，點選項目可切換預覽，「×」可移除
- 按「為 N 張圖產生圖示」，每張圖會輸出到各自的子資料夾（名稱依輸出名稱規則；同名時自動加上 `-2`、`-3`）
- 所有圖片套用相同的樣式與平台設定；Android 自訂圖層不適用於批次
- 單張圖片失敗不會中斷整批，完成後會顯示失敗數量，滑鼠移到上面可查看原因

## 圖片集模式

給 App 內使用的一般圖片（按鈕、插圖、背景等），產生各種螢幕密度的版本。

1. 切換到頂部的「圖片集」
2. 拖入或選取圖片（可多選）
3. 在左欄勾選輸出目標：**Xcode Image Set** 與／或 **Android drawable**
4. 每張圖可修改 **名稱** 與 **@1x 寬度**，下方會即時列出各密度的實際尺寸
5. 按「產生」

**@1x 寬度預設值**：點陣圖視為 @3x（原圖寬度 ÷ 3）；SVG 使用原始寬度。高度依原圖比例自動計算。

輸出結構：

```
ios/Banner.imageset/
  Banner.png          @1x
  Banner@2x.png       @2x
  Banner@3x.png       @3x
  Contents.json
android/res/
  drawable-mdpi/banner.png      1x
  drawable-hdpi/banner.png      1.5x
  drawable-xhdpi/banner.png     2x
  drawable-xxhdpi/banner.png    3x
  drawable-xxxhdpi/banner.png   4x
```

Android 的資源名稱只允許小寫英文、數字與底線，會自動轉換（例如 `My Icon-2` → `my_icon_2`、`3D view` → `img_3d_view`）。

## 設定

點頂部列右側的齒輪開啟。

| 分類 | 選項 | 說明 |
|---|---|---|
| 外觀 | 跟隨系統／淺色／深色 | 頂部列的月亮／太陽按鈕可快速切換 |
| 外觀 | 語言 | 跟隨系統、繁體中文、简体中文、English |
| 輸出 | 輸出名稱 | 可用 `{name}`（原檔名）、`{date}`（日期 YYYYMMDD）、`{time}`（時間 HHmmss），例如 `{name}-{date}` |
| 輸出 | 完成後自動開啟資料夾 | 產生完成後自動在檔案總管中顯示 |
| 輸出 | 記住上次的輸出位置 | 存檔對話框從上次的位置開始 |
| — | 重設所有設定 | 所有設定回到預設值（會先確認） |

## 常見問題

**安裝時出現「Windows 已保護您的電腦」？**
安裝檔尚未進行程式碼簽章。點「其他資訊 → 仍要執行」即可。

**iOS 圖示四個角變成白色？**
iOS 要求方形滿版圖示，圓角由系統自動裁切。如果原圖本身畫了圓角，透明的角落會被補成背景色（預設白色）。請使用方形滿版的原圖。

**Android 主題圖示變成一整塊方形？**
單色圖層只保留圖案輪廓（透明度）。請在「自適應圖層」中指定一張**透明背景**的前景圖，或另外指定單色圖片。

**圖片中文字的字型跑掉？**
SVG 中的文字會使用系統字型渲染。請在設計軟體中先把文字轉為外框。

**設定儲存在哪裡？**
儲存在 `%LOCALAPPDATA%\com.shawn.tauricon`。解除安裝時可選擇一併刪除。

**圖片會被上傳嗎？**
不會。所有處理都在本機完成，Tauricon 不會連線到任何伺服器。
