## Features

- **One image, every platform**: iOS / iPadOS, watchOS, macOS, Android, Windows, Web / PWA and Tauri
- **SVG support**: every size is rendered straight from the vector, so even 16px icons stay sharp
- **Ready-to-use output**: Xcode `AppIcon.appiconset` (with `Contents.json`), macOS `.icns`, Windows `.ico`, Android `mipmap` folders, PWA `manifest`
- **Store-compliant**: App Store icons have no alpha channel; the Play Store icon stays a 32-bit PNG
- **Style editor**: solid or gradient background, padding, corner radius, and the macOS template (inset, rounded corners, shadow)
- **Android adaptive icons**: separate images for the foreground, background and monochrome (Android 13 themed icon) layers
- **Batch processing**: full icon sets for many images at once
- **Image sets**: Xcode image sets (@1x/@2x/@3x) and Android drawables for in-app images
- **Live preview**: platform mask shapes, small-size legibility and a browser tab mockup
- ZIP or folder output, lossless PNG optimization, dark mode, Traditional Chinese / Simplified Chinese / English UI

## Download and install

### Requirements

- Windows 10 or 11 (64-bit)
- Microsoft Edge WebView2 (built into Windows 11; the installer downloads it if missing)

### Installing

1. Download the latest `Tauricon_x.y.z_x64-setup.exe` from [Releases](../../releases)
2. Run it, pick the installer language and follow the steps (no administrator rights needed)
3. Open **Tauricon** from the Start menu

> **Seeing "Windows protected your PC"?**
> The installer isn't code-signed yet, so Windows SmartScreen shows this warning. Click **More info → Run anyway** to continue.

### Uninstalling

Go to **Settings → Apps → Installed apps**, find Tauricon and choose **Uninstall**.

## Quick start

1. **Load an image**: drag it into the window or press `Ctrl+O` (1024×1024 or larger, or an SVG, is recommended)
2. **Adjust the style** (optional): background, padding and corner radius on the left
3. **Pick platforms** on the right
4. **Generate**: choose ZIP or folder output and click **Generate** (or press `Ctrl+Enter`)

The full user guide is currently available in Traditional Chinese: [docs/user-guide.md](docs/user-guide.md).

## Building from source

Requirements: [Node.js](https://nodejs.org/) 20+, [Rust](https://rustup.rs/) (stable) and the Visual Studio C++ build tools ("Desktop development with C++" workload)

```powershell
git clone <repo-url>
cd tauricon
npm install
npm run tauri dev      # development
npm run tauri build    # installer, written to target/release/bundle/nsis/
cargo test -p icon-core
```

### Command line

Generate icons with the core engine, without the UI:

```powershell
cargo run -p icon-core --release --example generate -- logo.svg AppIcons.zip ios android
```

Pass style options as JSON in the `ICON_OPTIONS` environment variable, e.g. `{"cornerRadius":0.2,"macosTemplate":true}`.

## Project layout

| Path | Contents |
|---|---|
| `crates/icon-core` | Core engine (Rust): loading, rendering, styling, platform outputs |
| `crates/icon-core/presets` | Platform specs (JSON); change sizes without touching code |
| `src-tauri` | Tauri command layer |
| `src` | React UI |
| `src/locales` | Translations; add a language by adding one JSON file |
| `design/app-icon.svg` | App icon source (`src-tauri/icons` is generated by Tauricon itself) |
